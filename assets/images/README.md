# Images

This theme uses remote placeholder images (picsum.photos for photos, pravatar.cc for
author avatars) so it works immediately with no assets to upload. To use your own:

1. Drop your image files in this folder (e.g. `assets/images/hero.jpg`).
2. Replace the matching `src="https://picsum.photos/..."` URL in the relevant HTML
   file, or in `assets/js/script.js` for images used across the blog card grid
   (search results, sidebar widgets, footer "Popular Posts").
3. Keep an `alt` attribute on every image that describes what it shows.

Recommended sizes:
- Card / grid thumbnails: 480×300
- Article feature image: 1400×800
- Author avatars: 128×128
- Open Graph / social share image: 1200×630
